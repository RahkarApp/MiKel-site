# Project instructions

## Shared design-system reference
All chats and agents working in this project must read [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md) before changing page appearance, typography, colors, layout, components, animation, or responsive behavior.
Treat the document as the shared reference for this repository. Explicit new user instructions take priority.
Inspect the current HTML and its final CSS overrides as well: the document is a dated source snapshot, not a runtime stylesheet.
Preserve approved compact typography on about.html and updates.html, original Persian text, UTF-8 encoding, the 1500ms testimonial dwell, pale orange quotation badges, and existing responsive behavior unless the user requests a change.
After an approved design change, update the relevant sections and source snapshots in DESIGN_SYSTEM.md.
The app is buildless HTML/CSS/JavaScript: index.html, about.html, updates.html, blog.html, tool-*.html, and assets/. Every page loads assets/design-system.css for shared tokens, font, header, buttons and footer; all inner pages load assets/page-base.css for compact layout. Shared navigation, popover and FAQ behavior lives in assets/site-interactions.css and assets/site-interactions.js. Keep tool and blog main content empty until requested.
This instruction makes the reference discoverable within this project; it does not change OS permissions or grant a different chat access to an unrelated filesystem.
Mobile homepage: hero title is 28px and media comes before copy; purchase titles are 11px with a separate help-control column and flowing prices. Testimonials show one horizontal card on mobile and three on desktop; assets/testimonials.js owns carousel sizing, 1500ms dwell and looping.

Latest typography instruction: smaller text applies ONLY at widths <=720px. Desktop typography is restored: homepage title 56px, inner-page titles 40px (36px tablet), body 16px. Mobile retains homepage title 28px, inner-page title 24px, purchase titles 11px and body 14px. Desktop restoration rules are scoped to min-width:721px.

Mobile navigation is an opaque left-side drawer (<=720px), portaled to body by site-interactions.js, with a green blurred backdrop, focus management and scroll lock. Do not restore duplicated inline navigation toggles. Desktop navigation stays inline.
Homepage features use four concentric circles with exactly six accounting icons equally spaced 60 degrees apart ONLY on the outermost circle. Scroll moves the outer orbit clockwise in 60-degree steps; icons counter-rotate to stay upright. The icon arriving at twelve o'clock receives a dark brand fill, raised scale and shadow, and its corresponding Persian text appears at the right. Other rings keep their colors. Only the innermost circle gets a bold progress stroke. Its fill and the outer orbit rotation share one requestAnimationFrame progress value, a 520ms cubic ease-out, and the same six stops: both start, pause, reverse and finish together. Do not reintroduce independent CSS transform transitions or raw-scroll stroke updates. Preserve the enlarged center Mikel logo and reduced-motion vertical fallback. Component behavior: assets/features-timeline.js; styles: assets/site-interactions.css.
