# Project instructions

## Shared design-system reference
All chats and agents working in this project must read [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md) before changing page appearance, typography, colors, layout, components, animation, or responsive behavior.
Treat the document as the shared reference for this repository. Explicit new user instructions take priority.
Inspect the current HTML and its final CSS overrides as well: the document is a dated source snapshot, not a runtime stylesheet.
Preserve approved compact typography on about.html and updates.html, original Persian text, UTF-8 encoding, the 1500ms testimonial dwell, pale orange quotation badges, and existing responsive behavior unless the user requests a change.
After an approved design change, update the relevant sections and source snapshots in DESIGN_SYSTEM.md.
The app is buildless HTML/CSS/JavaScript: index.html, about.html, updates.html, and assets/.
This instruction makes the reference discoverable within this project; it does not change OS permissions or grant a different chat access to an unrelated filesystem.
